## Public/restricted boundary

| Information | Public inventory | Restricted annex |
|---|---|---|
| Object identity and public token facts | Include when verified | Full evidence and query logs |
| Donor credit | Agreed public credit only | Legal identity and contacts |
| Title instrument | Hash/non-sensitive custodian reference | Executed instrument and internal review |
| Appraisal, tax, valuation | Exclude | Restricted if retained |
| Custody | Public address/reference if safe | Signers, hardware, security procedures |
| Preservation | Summary, hashes, public package refs | Private storage locations and access controls |
| Risk | Public material caveats | Sensitive threat/risk analysis |
