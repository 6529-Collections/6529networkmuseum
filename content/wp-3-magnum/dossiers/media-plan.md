# Media plan and current presentation disposition

## Current public use

The five photographs already appear in the signed Wave Storm proposal as the
historical media for work parts 2–6. This corpus may reference or embed those
exact upstream URLs in the proposal’s Wave context. Each display carries:

- the artist/Magnum credit supplied in the signed proposal;
- `All Rights Reserved`; and
- the label **Wave-source historical proposal media**.

This is a narrow presentation disposition for the live proposed gift. It does
not create a repository copy or authorize a new image manifestation. The exact
join is machine-readable in [`wave-media-join.json`](../machine/wave-media-join.json)
and the human-readable credit/rights record is [Source and rights record](source-and-rights-record.md).

## Rights matrix

| Use | Current disposition | Required record before change |
| --- | --- | --- |
| Reference/embed the exact upstream URL in the historical proposal Wave | Allowed in the narrow labelled proposal context | Preserve the exact URL, credit, rights label, source part, and token link in the media join |
| Public Collection page | Blocked | Written display/publication permission and admitted Collection record |
| Download or full-resolution delivery | Blocked | Explicit distribution permission and reviewed delivery policy |
| Crop, thumbnail, recompression, responsive `srcset`, or other derivative | Blocked | Component-specific derivative permission and source-fixity manifest |
| IIIF manifest or tiled service | Blocked | IIIF-specific permission, retained source, and reviewed rights manifest |
| Preservation copy or derivative | Blocked | Preservation permission, retained source bytes, PREMIS/provenance record, and approved storage plan |
| Marketplace screenshot, substituted crop, or cover-card reuse | Blocked | Separate asset record and explicit rights review |

No JPEG, thumbnail, AVIF, WebP, responsive derivative, or IIIF manifest is
generated or committed by this corpus. Arweave availability and a matching hash
are technical observations; they do not grant preservation authority.

## Display colophon

The frontend-facing publication string for every current work media reference
is:

> [Artist] / Magnum Photos, [title and place], [year]. © [artist]/Magnum Photos
> 2022. All Rights Reserved. Wave-source historical proposal media.

The exact artist/title/year form comes from the signed proposal row and the
Work’s caption history. The colophon does not claim download, full-resolution
delivery, preservation, Collection status, or copyright ownership by the
Museum.
