# Chronologies

This dossier separates historical dates, publication dates, chain observations,
and Museum-process observations. A date in one column does not imply an event in
another. In particular, a mint block is not a listing, sale, transfer to the
Museum, or accession date.

## Future correction rule

If Magnum, an artist, an estate, a platform archive, or a governance source
supplies a later date or correction, append it as a dated amendment. Preserve
the prior statement and use `supersedes` only where the new source actually
changes the earlier assertion. Mint, publication, listing, transfer, title,
rights, custody, acceptance, and accession dates must continue to be recorded
as separate event types.
