# WP-3 source register

Access date for web sources in this register: 8 August 2026 UTC, unless a
historical access/archive date is stated. The register is a research apparatus,
not a claim that every source is retained by the Museum. A URL is a locator;
the source's authority, scope, and limitations are recorded below.

## How to read the register

`A` is a direct chain, token, or byte observation; `B` is an authoritative
issuer, artist, estate, archive, institution, or governance source; `C` is a
Museum technical observation; `D` is a reputable third-party historical source;
`E` is Museum interpretation. The source class does not make a claim true by
itself. Each publication must preserve the source's attribution and limits.
