# Keys and Gates - media and visual-description record

This record joins the sixteen selected outcomes to the Museum's visual
descriptions, source observations, fixity, and contextual presentation copies.
The [current display authority](media-display-authorization-amendment-2026-08-11.md)
admits fourteen Works at 640, 1280, and 2400 pixels and restricts OUT-004 and
OUT-011 to 640 pixels.

## Record boundary

For each outcome, the active join is:

```text
selected outcome
  -> source observation and source fixity
  -> reviewed visual description
  -> typed Media record and exact presentation derivatives
  -> contextual visitor display with no download or reuse grant
```

The source observations remain upstream public submission evidence and are
not themselves Museum presentation links. The active derivatives are web
presentation surrogates, distinct from source downloads, preservation masters,
token manifestations, and evidence of title or accession. Historical delivery
states remain in the append-only amendment chain.

## Accessibility state

All sixteen descriptions have been checked against the active presentation
copies. They describe visible material without identifying people or inferring
legal status. OUT-004 keeps the figures non-identifying; OUT-010 describes the
visible torso without inferring identity or age; OUT-011 records the document's
reduced legibility without transcribing an identifier.

The current manifest, accessibility inventory, typed Media records, and this
table form a one-to-one set of sixteen. CI binds every admitted derivative to
its exact source fixity, transform profile, public width, display authority,
and no-reuse boundary.
