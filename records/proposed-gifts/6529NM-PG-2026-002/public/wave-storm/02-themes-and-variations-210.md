# Vera Molnár — *Themes and Variations* #210

Vera Molnár, in collaboration with Martin Grasser, *Themes and Variations* #210, 2023. The project is a fixed edition of 500 unique, non-static generative outputs on Ethereum through Art Blocks infrastructure and Sotheby's Gen Art.

The exact token is `eip155:1/erc721:0xe034bb2b1b9471e11cf1a0a9199a156fb227aa5d/210`, with token hash `0xd0a3be9aa1a3e101a12ec038ceb71a18846dbc62eac3e91fb425232e7820a318`. The official metadata identifies the Flex engine, a 6×6 grid, the feature `Letters: NFT`, the palette `b #00188D, b #F3F0E9`, and `Vera Letter: F bold`.
