# Working notes

This directory preserves reasoning, alternatives, unresolved questions, and planning inputs. Nothing here is adopted policy merely because it is committed.

- Use dated files under `notes/wip/`.
- State the evidence basis and implementation status.
- Promote conclusions into `docs/`, `policies/`, or `records/` only with an explicit status change and, where required, governance authority.
- Keep `INDEX.md` current.
